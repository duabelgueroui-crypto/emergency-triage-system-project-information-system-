# emergency-triage-system-project-information-system-
Smart Emergency Triage System

This project implements a decision-support information system designed to assist emergency department triage. The system organizes patient data, records clinical information, and applies a rule-based scoring logic to determine urgency levels.

The objective is to standardize triage evaluation and support healthcare professionals with structured digital tools.

Technologies used:

Python (core application logic)

PyQt5 (graphical user interface)

SQL relational database

Rule-based triage decision engine

MERISE information system modeling

The system is an academic implementation inspired by international triage standards such as ESI and CTAS. It is intended as a prototype decision-support tool and does not replace medical judgment.
